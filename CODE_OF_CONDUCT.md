# 行為準則 / Code of Conduct

請保持尊重、就事論事、開放。騷擾、歧視、公開他人私人資訊都不被接受。
討論以行銷技能與工具本身為主；上游作者與社群成員的貢獻應被公允對待。

有疑慮請透過本 repo 的 security advisory 流程私下回報，見 [`SECURITY.md`](SECURITY.md)。

---

Be respectful, constructive, and open. Harassment, discrimination, and sharing another
person's private information are not acceptable. Keep discussion on the marketing skills
and the tooling itself, and treat the upstream author's and the community's contributions
fairly.

Report concerns privately through this repository's security advisory flow; see
[`SECURITY.md`](SECURITY.md).
